قوانین و شرایط استفاده

این وب‌سایت یک پروژه آموزشی است. استفاده از آن به معنی پذیرش موارد زیر است.

  1. محتوای نمایشی: خبرها، نتیجه بازی‌ها، جدول لیگ و پخش زنده ساختگی هستند و نباید به‌عنوان اطلاعات واقعی استفاده شوند.
  2. حریم خصوصی: سایت اطلاعاتی از بازدیدکنندگان ذخیره نمی‌کند. فقط تنظیم‌های ظاهری (اندازه متن و حالت تیره) در مرورگر خودتان نگه داشته می‌شود.
  3. ارسال پیام: متن فرم تماس، نام و ایمیلی که می‌نویسید از طریق سرویس FormSubmit به ایمیل ما فرستاده می‌شود و فقط برای پاسخ‌دادن استفاده می‌شود.
  4. دسترس‌پذیری: سایت برای استفاده همه کاربران طراحی شده است. اگر مشکلی در استفاده دیدید، از صفحه تماس به ما اطلاع دهید.
  5. تغییرات: ممکن است محتوا و ظاهر سایت بدون اطلاع قبلی تغییر کند.
